# 上級者向けの追加機能案

以下は未実装の提案です。既存の解像度変更、局ロゴ管理、マクロ、字幕保存、並列キューとは別の拡張です。

| 優先度 | 機能 | 内容 |
|---|---|---|
| 高 | 24/30/60fps混在の区間解析 | 区間ごとにケイデンスを調べ、VFR出力または60p維持を選ぶ。今回のサンプル判定型IVTCの次段階。 |
| 高 | 変換前の比較プレビュー | 元映像・逆テレシネ・解除後を同じフレームで比較。フィールド単位のコマ送り、拡大、縞の表示。 |
| 高 | CPUフィルタとGPUエンコードのパイプ接続 | 可逆中間ファイルを全編保存せず受け渡す。逆テレシネ使用時のディスク負荷・待ち時間を抑える。中止・音声同期も管理。 |
| 高 | 品質・容量の試算 | 代表区間だけ試し、複数の品質値で容量・速度・VMAF/SSIMを比較して本変換を決める。指標は絶対評価としない。 |
| 高 | 複数音声の保持 | 主音声・副音声・解説・5.1chを選択し、言語タグ・既定音声・チャンネル構成も保存。 |
| 高 | 放送障害の可視化 | TSドロップ、PTS飛び、音声欠落をタイムラインに示し、元データ由来の欠損と変換失敗を区別する。 |
| 中 | フィルタグラフの編集・実行計画表示 | 処理順とCPU/GPU境界を表示し、クロップ・縮小・ノイズ除去などの順序を管理。競合設定を事前検証。 |
| 中 | 色・階調の明示管理 | BT.601/709/2020、limited/full、10bit、ディザリングを明示し、不用意な色変換を防ぐ。 |
| 中 | 自動クロップ候補 | 複数場面から黒帯の候補を出し、字幕や場面変化を確認してから確定する。 |
| 中 | 字幕・音声同期の調整 | トラックごとの遅延をプレビューし、ミリ秒単位で指定。CMカット後も同期状態を検証する。 |
| 中 | リソースに応じた並列制御 | GPUエンコード・CPU解析・ディスクI/Oごとに上限を設け、録画時間帯は負荷を抑える。 |
| 中 | 区間単位の再開 | 中間成果物の入力指紋と設定を記録し、失敗した工程から再開する。完成ファイルは最後に検証・結合。 |
| 中 | バージョン固定と再現用レシピ | 各ツールの版・ハッシュ・設定・判定結果をまとめ、同じ環境を再構築できるようにする。 |
| 低 | 自動ルールによるプリセット選択 | 局・ジャンル・番組名・解像度などで選択し、適用理由と優先順位を確認できるようにする。 |

まずは「比較プレビュー」「パイプ接続」「複数音声」の3つが、効果を確認しやすく実用性も高い候補です。
